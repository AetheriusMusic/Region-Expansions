# AETHERIUS' REGION EXPANSIONS

### This is a Rain World mod that adds various rooms in **Vanilla** and **Downpour** regions.

# INSTALLATION

You can download the mod through the [Steam Workshop page](WIP), but if you want to download it via GitHub and not via Steam, you need to put the `aetheriusRegionExpansions` folder inside `C:/Program Files (x86)/Steam/steamapps/common/Rain World/RainWorld_Data/StreamingAssets/mods`, assuming you have Rain World installed via Steam.
